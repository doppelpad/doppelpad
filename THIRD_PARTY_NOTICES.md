# Third-party notices

This file covers the parts of Doppelpad that are not Rust crates or npm packages. The
licenses of the crates and packages compiled into `doppelpad-gui` and `doppelpad` (`.exe`
on Windows) are in [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md), which the setup, the
AppImage and the macOS app carry next to this file.

## Bundled drivers

The Windows setup of Doppelpad contains the official, unmodified setups of two drivers and
runs them when the driver is missing. Both are separate programs from Nefarius Software
Solutions e.U. They appear in *Installed apps* under their own names, and uninstalling
Doppelpad does not remove them.

## WebView2 loader

`WebView2Loader.dll`, installed next to `doppelpad-gui.exe`, finds the Microsoft Edge
WebView2 Runtime that draws the app's window. It is part of the Microsoft WebView2 SDK
(1.0.3650.58), unmodified, and comes with the crate webview2-com-sys. Builds with the MSVC
toolchain link the loader's static library into `doppelpad-gui.exe` instead.

## Libraries in the Linux AppImage

The Linux AppImage carries the system libraries the app needs from Ubuntu 22.04, unmodified:
WebKitGTK, which draws the app's window, GTK and the libraries they use, and
libayatana-appindicator for the tray icon. They are separate shared libraries under their
own licenses, most of them the GNU Lesser General Public License. Each release has
`Doppelpad_<version>_amd64_libraries.txt` beside the AppImage. It lists every library with
the Ubuntu package it comes from and that package's source package and version, then gives
each package's copyright file in full and the license texts (LGPL, GPL and others) these
refer to. The source code of each package is available from Ubuntu at
<https://launchpad.net/ubuntu/+source/SOURCE-PACKAGE/VERSION>.

One of these libraries is under the GNU General Public License version 3 alone:
libayatana-indicator, which libayatana-appindicator loads for the tray icon. As it runs in
the app's process, the AppImage as a whole is distributed under the terms of the GPL
version 3. Doppelpad's own code stays under the MIT or the Apache 2.0 license, which both
allow this, and its source is in this repository at the release's tag. Ubuntu's source
package of libayatana-indicator, of the version the AppImage carries, is in
`Doppelpad_<version>_amd64_gpl_sources.tar` beside the AppImage.

## The macOS app

The macOS app contains no third-party libraries besides the Rust crates and npm packages. It
uses the frameworks of macOS itself (AppKit, WebKit, IOKit and the others), which are part of
the system and not shipped with the app.
