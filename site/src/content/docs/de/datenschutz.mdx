## Kurz gesagt

Diese Website setzt keine Cookies, nutzt kein Tracking und keine Analysedienste und lädt nichts
von fremden Servern. Schriften, Skripte und die Suche kommen alle von dieser Website selbst.
Personenbezogene Daten fallen nur beim Hosting an: GitHub, der Betreiber von GitHub Pages,
protokolliert die IP-Adressen der Besucher.

## Speicher im Browser

Wählen Sie ein helles oder dunkles Farbschema, merkt sich die Website diese Wahl im lokalen
Speicher Ihres Browsers (`localStorage`). Welche Abschnitte der Seitenleiste offen sind, merkt sie
sich bis zum Schließen des Tabs (`sessionStorage`). Diese Angaben verlassen Ihr Gerät nicht und
werden nur gespeichert, weil Sie die Website so bedienen (§ 25 Abs. 2 Nr. 2 TDDDG). Sie können
sie jederzeit in Ihrem Browser löschen.

## Links zu anderen Websites

Die Downloads, der Quellcode und die Treiber liegen auf GitHub. Wenn Sie einem solchen Link
folgen, gilt dort die Datenschutzerklärung des jeweiligen Anbieters.
